## 1. 단계 — UI 선행 (2026-08-19 개정)

기존 M0~M5는 "실행 계층 → UI" 순서였다. **더미 데이터로 화면을 먼저 확정하고 서비스를 만들어가는 방식**으로 개정한다. 근거는 [ui_specification §1](ui_specification.md).

| Phase | 범위 | 기간 감 | 통과 게이트 |
| :--- | :--- | :--- | :--- |
| **P0** | **데이터 계약 확정** — [data_contract.md](data_contract.md) | 2~3일 | 모든 지표가 **실제 체결 데이터에서 계산 가능**한지 검토 통과 |
| **P1** | 픽스처 생성기 — 3 시나리오(상승·하락·횡보), 시드 고정 | 2일 | **하락 시나리오에서 MDD가 정직하게 보이는가** |
| **P2** | **Admin UI** — 대시보드·포지션·매매로그·백테스트 뷰 | 1~2주 | 인증 뒤에서만 접근. 퍼블릭 노출 0 |
| **P3** | **Public UI** — `/candela` 4개 화면 (ko·en·ja) | 1~2주 | **퍼블릭 라우트 미등록 상태**로 개발 (G-2가 빌드로 강제) |
| **P4** | Worker·백테스트 (private 저장소) + 킬스위치 실배선 | 3~4주 | 수수료·거래세·슬리피지 반영, look-ahead·상폐 누락 점검 통과 |
| **P5** | 모의투자 → 관망 → 실계좌 소액 → 퍼블릭 공개 | 3개월+ | 아래 §2·§3 |

**P0을 픽셀보다 먼저 두는 이유**: UI 선행의 최대 위험은 더미 데이터가 스키마를 결정해버리는 것이다. 보기 좋은 지표로 목업을 만들면 실제 체결에서 계산 불가능한 값이 화면에 박히고, UI와 Worker를 둘 다 다시 만들게 된다.

**P2가 P3보다 먼저인 이유**: 실측 결과 `src/components/admin/`은 i18n 게이트 제외 구역이라 **한국어 하드코딩이 허용**된다. 디자인 반복을 마찰 없는 쪽에서 먼저 돌리고, 확정된 패턴을 언어팩이 필요한 퍼블릭으로 옮긴다.

## 2. 승격 게이트 — 건너뛰지 않는다

```
백테스트 ──► 모의투자(1~2개월) ──► 실계좌 소액 ──► 증액
```

이 순서를 건너뛰면 높은 확률로 돈을 잃는다. **관망 구간의 유혹이 가장 크다** — 결과가 나쁘면 고치고 싶고, 좋으면 키우고 싶어진다. 둘 다 하지 않는 것이 관망의 목적이다.

## 3. 퍼블릭 공개를 앞당기지 않는다

UI가 P3에서 완성돼도 **실데이터 3개월 전에는 공개하지 않는다.** 화면이 준비된 상태에서 이 유혹이 가장 커지므로, 의지가 아니라 [ui_specification §2](ui_specification.md)의 빌드 게이트로 막는다.

실적 3개월치 없는 실적 페이지는 홍보가 되지 않는다. 대신 **P2~P4 기간에 "만드는 과정" 콘텐츠를 [Builder's Log](../builders-log/publishing_guide.md)에 쌓는다.** [product_strategy §8](product_strategy.md)의 성공 기준대로, 아키텍처 서사가 실적보다 오래 간다.

## 3-1. UI 선행이 만드는 위험과 대응

| 위험 | 대응 |
| :--- | :--- |
| 🔴 더미 데이터가 든 퍼블릭 실적 페이지의 실수 공개 — **날조된 기록 게시** | 게이트 3중 ([ui_specification §2](ui_specification.md)): 데이터 소스 선언 · 빌드 차단 · 해제 불가 워터마크 |
| 🟠 더미가 스키마를 결정 | P0(계약)을 P1(픽스처)보다 먼저 |
| 🟠 예쁜 숫자에 대한 정서적 고착 | 픽스처 3 시나리오 — 하락장 통과가 게이트 |
| 🟡 백테스트 엔진(진짜 어려운 부분) 지연 | P4를 늦추지 않는 것을 명시적 게이트로 |
| 🟡 작동하지 않는 킬스위치 목업 | **킬스위치는 목업하지 않는다** — P4에서 실배선과 동시 |

| # | 항목 | 결정 |

| D-5 | 실적 공개 집계 단위 | **주간 고정** — `aggregation`을 선택지가 아닌 고정값으로 둔다. 선택지로 두면 언젠가 일별로 바꾸게 되고, 그 순간 포지션이 역산된다 |

## 5. 하지 않기로 한 것

*   **자동매매의 타인 제공** — 투자자문업·투자일임업 규제 진입. 제품 정의에서 영구 배제
*   **유료 구독·시그널 판매** — 유사투자자문업 신고 대상
*   **실시간 시세 재배포** — 라이선스 위반 소지
*   **분봉 단타** — 상시 웹소켓이 필요해 "가변비용 0" 운영 철학과 충돌. P5 이후 재검토 가능
*   **ML 기반 전략(초기)** — 검증이 불가능해진다. 룰 기반으로 시작
