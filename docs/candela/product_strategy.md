## 1. 한 줄 정의

**"AI로 만든 개인 자동매매 시스템, 그리고 그 시스템이 실제로 작동한다는 공개 증거."**

Candela는 투자 서비스가 아니다. **PriSincera의 제작 역량을 증명하는 사례 연구(Case Study)**이며, 자동매매는 그 사례의 소재다.

## 2. 명칭

**Candela** — 라틴어 '촛불'이자 SI 광도 단위. 캔들차트와 "측정 가능한 밝기"를 동시에 함의한다. Sylphio·PriSincera의 라틴 계열 브랜드 톤과 형제 관계를 이루며, 실적을 투명하게 공개한다는 컨셉과 어원이 일치한다.

> 착수 전 상표·도메인 가용성 확인 필요.

## 3. 이원 구조 — 하나의 이름, 두 개의 시스템

| | Trading Core | Public Web |
| :--- | :--- | :--- |
| 대상 | 오직 제작자 본인 | 불특정 다수 |
| 목적 | 실제 자산 운용 | 제작 역량 증명 |
| 위치 | `candela-worker` (private 저장소) | `/candela` (본 저장소) |
| 공개 | 전면 비공개 | 전면 공개 |

**자동매매는 타인에게 제공하지 않는다.** 이 원칙이 무너지는 순간 투자자문업·투자일임업 규제 영역으로 진입하므로, 제품 정의 자체에 못 박는다.

## 4. 포지셔닝 — "투자 서비스"가 아닌 이유

PriSincera의 정체성은 [service_overview](../core/service_overview.md)가 정의하듯 **"20년 기획 감각에 AI를 더해 새로운 서비스를 만들어 가는 과정의 공개"**다. ReLearn·Sylphio·Builder's Log가 모두 그 서술 위에 있다.

Candela가 수익률을 전면에 세우면 브랜드에 "돈 버는 법" 색이 입혀지고, ReLearn의 성장 서사와 충돌한다. 따라서:

*   **첫 화면 헤드라인은 수익률이 아니라 아키텍처다.**
*   실적은 상품이 아니라 **시스템이 작동한다는 증거**로만 배치한다.
*   [Builder's Log](../builders-log/publishing_guide.md)의 연장선으로 읽히게 한다 — 그 문서가 "어떻게 만들었는가"를 서술하고, Candela가 "그래서 작동한다"를 보인다.

이 포지셔닝을 지키면 톤 충돌이 해소될 뿐 아니라 포트폴리오 일체감이 오히려 강해진다.

## 5. 공개 원칙 (Disclosure Policy)

퍼블릭 페이지에서 **반드시 지킨다**:

1.  **무료.** 대가를 받고 종목·매매 판단을 제공하는 순간 유사투자자문업 신고 대상이 된다. 구독·유료 시그널은 영구 배제한다.
2.  **금액·수량 비공개.** 비율과 수익률만 공개한다. 자산 규모를 노출하지 않는다.
3.  **사후 공개.** 매매 로그는 T+1 이상 지연 공개한다. 실시간 공개는 사실상 리딩방이다.
4.  **주간 집계 우선.** 일별 수익률 시계열은 보유 종목 수가 적을 때 종목·비중을 역산당한다. 종목 비공개 정책이 수익률 공개로 무력화되지 않도록 집계 단위를 조정한다.
5.  **원시 시세 재배포 금지.** 증권사 API로 받은 시세를 웹에 그대로 노출하지 않는다(라이선스 위반 소지). 파생 데이터만 게시한다.
6.  **손실 은폐 금지.** MDD와 최악의 달을 첫 화면에 노출한다. 수익률만 큰 폰트로 띄운 페이지는 즉시 신뢰를 잃는다.
7.  **백테스트와 실체결 구분 표기.** 섞어서 제시하지 않는다.

## 6. 페이지 구성 (`/candela`)

| 경로 | 내용 |
| :--- | :--- |
| `/candela` | 랜딩 — 시스템 소개, 아키텍처 요약 |
| `/candela/performance` | 실적 대시보드 — 자산곡선·MDD·샤프·승률, KOSPI 벤치마크 대비 |
| `/candela/journal` | 매매 로그 (T+1 사후 공개) |
| `/candela/notes` | 전략 해설·개발 회고 |

경로 배치 근거는 [system_architecture §2](system_architecture.md)를 참조한다.

## 7. i18n 정책

본 저장소는 ko/en/ja 3로케일 체계다. Candela는 **ko 우선**으로 출시하고, 실적 3개월 축적 후 en·ja를 확장한다. 초기 번역 부채를 지지 않는다.

## 8. 성공 기준

수익률이 아니다.

*   **1차**: 시스템이 3개월간 사람 개입 없이 무사고로 가동
*   **2차**: 아키텍처 문서·회고가 Builder's Log 유입을 만들어냄
*   **3차**: "이 사람은 실제로 만들어서 돌린다"는 증거로 기능

수익률은 위 세 가지가 충족된 뒤의 부수 지표다.
