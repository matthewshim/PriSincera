## 4. 방법 — 2트랙

### 4-0. 하네스 전제 (검증 완료, 2026-11-01)

- `puppeteer-core` + 설치된 Chrome(`/Applications/Google Chrome.app`). **스크래치패드에 설치**하여 레포·`package.json` 무오염.
- **단순 `fullPage` 캡처는 무효**: 홈 첫 캡처가 별 배경만 찍히고 텍스트 0 — 스크롤 리빌(IntersectionObserver) 의존. **스크롤 프라이밍(전 구간 순회) → 상단 복귀 → 뷰포트 구간별 연속 캡처**가 필수. 적용 후 홈 10샷 정상 확보 확인.
- **로케일은 URL이 아니라 `localStorage.prs_locale`**: `evaluateOnNewDocument`로 주입 후 로드(동일 오리진 선행 방문 필요).
- 레포 경로가 한글(NFD)이라 `cd` 직접 지정 실패 → 글롭(`cd /Users/.../문서*/PriSincera/www`) 경유.

## 6. 이슈 분류 규칙 — R / P / N

적발 이슈는 **반드시 3종 중 하나로 분류**합니다.

| 분류 | 의미 | 처리 |
| :--- | :--- | :--- |
| **R (회귀)** | 이번 커밋이 깨뜨림 | 즉시 수정 → 재캡처 비교 |
| **P (선재)** | 원래 그랬음 | `task_backlog.md` 등재 |
| **N (규범 결함)** | 조항대로 했는데 눈에 틀림 | **design_system 개정 대상** |

> **N 처리 원칙 — 조항 추가 금지**
> 이 문서는 리비전 25건 중 24건이 "QA 환류 → 조항 추가"로 비대해졌고, v6.1이 그것을 **예산(budget) 집행**으로 전환한 직후입니다. 이번 QA 결과를 또 조항으로 받으면 같은 경로를 반복합니다.
> **N은 ① 기존 조항 수정 ② `ci/pattern-budget.json` 지표화 ③ `design-check` 차원 추가 중 하나로 처리**하고, 새 절(§) 신설은 최후수단으로 둡니다.
