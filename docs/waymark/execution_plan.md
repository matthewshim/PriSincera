## 1. 경영 요약 (Executive Summary)

**Waymark**은 "결정의 갈림길에서 먼저 다가와 곁을 지키는 AI 동반자"다. 조언 콘텐츠는 포화됐지만 **결정의 순간에 함께 있어 주는 서비스**는 비어 있다 — 이 공백을 PriSincera의 네 번째 제품으로 선점한다. 부적합하다고 판단한 자동매매(Candela)에서 피벗했으며, 소개 페이지는 이미 라이브다. 본 계획은 **2026-11 설계 착수 → 2027-03 정식 출시(GA)**를 목표로 하며, **서버 AI·유료 백엔드 없이 운영비 ≈ 0원**(기존 Firebase 재사용 + 규칙·템플릿)인 1인~소규모 모델로 추진한다. 스택은 **기존 Firebase 재사용으로 확정**했고, 남은 핵심 요청은 **베타 사용자 확보·보안/컴플라이언스 범위**다(§9).

## 2. 배경 · 기회

| | 내용 |
| :--- | :--- |
| **문제** | 결정을 자주 내리는 실무 리더는 (1) 큰 결정의 외로움·사후 불안을 혼자 감당하고 (2) 지난 결정을 돌아볼 계기가 없어 후회를 반복한다. |
| **시장 공백** | "답(advice)"은 넘치나 "동반(company) + 회고 자산화"는 없다. **"서비스가 먼저 찾아온다"**는 기존 저널/노트 앱에 없는 차별 신호. |
| **왜 지금** | ① 개인화 LLM으로 "정서 동반자" 품질이 실현 가능 ② PWA·관리형 백엔드로 소규모가 운영 제품 출시 가능 ③ 실서비스 코드 착수 전이라 피벗 비용이 가장 낮음. |

## 3. 제품 개요

> 결정을 많이 내리는 사람을 위한 **결정 저널 + 먼저 찾아오는 AI 동반자 + 경험담**.

**핵심 루프**: ① 결정 기록 → ② (서비스가) **먼저 찾아옴** → ③ **경험담**(겪어 본 이의 이야기) → ④ 다시 보기(회고) → 회고를 익명 경험담으로 기여(선순환).

**원칙(브랜드 안전)**: AI는 **대신 결정하지 않는다** — 갈림길을 비추고 곁에 있을 뿐. 투자·자문식 오해를 구조적으로 차단.

## 4. 전략적 적합성

- **포트폴리오**: PriSincera(진심·태도·성장) 축에 정합. 자동매매(Candela)의 "돈 버는 법" 색을 걷어내고 **태도·동반**으로 전환.
- **진정성**: 제작자 집단(20년차 기획·PO·PM·리더)이 곧 사용자 → "만드는 사람이 쓰는 사람".
- **차별화(사내 자가잠식 방지)**: *"ReLearn은 성장을 돕고, Waymark은 결정을 지킨다."* 단위(반복 vs 개별 결정)·주도권(내가 vs 서비스가 먼저)·AI 톤(코치 vs 동반자)이 분리됨. MVP 단계 연동 금지.

## 5. 추진 범위 · 단계

### 5-1. MVP 범위 (오너 확정)
**풀 루프(경험담 포함) · 경험담=사용자 커뮤니티 제출 · 먼저찾아옴=시간 규칙 기반.**
포함: 결정 기록·타임라인·시간규칙 먼저찾아옴(**이메일+웹푸시 이중 채널**)·**동반 메시지(4톤 템플릿·LLM 없음)**·경험담 제출/수동검수/태그매칭·다시보기/회고·알림/설정.
제외(v2+): **서버 유료 AI·무제한 채팅**·임베딩 매칭·감정기반 AI 트리거·고급 추천·팀/공유·분석 대시보드·결제·네이티브 앱·ReLearn 연동.

### 5-2. 마일스톤

| 단계 | 핵심 산출물 | 목표 시점 | 승격 게이트 |
| :--- | :--- | :--- | :--- |
| **M0 설계·셋업** | 3종 명세 확정, 스택 셋업, 디자인 토큰 이식 | 2026-11 | 스택·예산 승인 |
| **M1 핵심 루프 알파** | 기록·홈·먼저찾아옴·AI 1~2모드·회고 | 2026-12 | 내부 dogfooding 통과 |
| **M2 경험담 + 4모드** | 제출·검수·매칭, AI 4모드 완성 | 2027-01 | 경험담 시드·검수 가동 |
| **M3 비공개 베타** | 초대·시드·알림 안정화·KPI 계측 | 2027-02 | 베타 KPI(리텐션·응답률) |
| **M4 공개 → GA** | 온보딩·성능·안정화·공개 | **2027-03** | 안정성·KPI 충족 |

## 6. 자원 · 비용 (비용 ≈ 0 재설계)

> **수익(유료 플랜)이 없으므로 MVP 운영비를 0에 수렴**시킨다. 비용의 주범이던 **서버 유료 AI를 제거**하고, AI는 **학습 안 하는 무료 티어(Groq·ZDR) 캡 체험 + 템플릿 폴백 → BYOK**로, 인프라는 **기존 Cloud Run·Firestore·Scheduler·이메일 엔진**(무료 쿼터 내)으로 운영한다(오너 결정 2026-10-24).

### 6-1. 비용 0 구조
| 요소 | 기존(비용 발생) | 재설계(비용 0) |
| :--- | :--- | :--- |
| 먼저 찾아옴 · 동반 | 서버 AI(유료) 종량 | **규칙·템플릿 + 체험 AI(Groq 무료·무학습·ZDR·캡)** → ₩0, 지속 BYOK |
| 경험담 매칭 | 임베딩 API | **태그·키워드**(API 0) |
| 경험담 검수 | AI 선필터 | **수동(오너)** MVP |
| DB·인증·호스팅·서버 | Supabase/Vercel 유료 | **기존 Cloud Run·Firestore·Auth·Hosting 재사용** |
| 스케줄·알림 | — | **기존 Cloud Scheduler→Cloud Run Job** · **이메일 엔진(기존)** + FCM 웹푸시(무료) |

### 6-2. 월 운영비
| 단계 | 활성 사용자 | 월 운영비 |
| :--- | :--- | :--- |
| 내부·알파(M0~M1) | ~10 | **≈ 0원** |
| 비공개 베타(M3) | ~100~300 | **≈ 0원** (무료 티어 내) |
| GA 초기 | ~1,000 | **≈ 0원** (Firestore 일 5만 읽기/2만 쓰기 · Functions 무료 쿼터 내 가정) |

> 핵심: **서버 AI·유료 백엔드 없음 → 사용량이 늘어도 비용이 0 근처 유지.** 유일한 변수는 **무료 티어 한도**(초과 시 그때 소액 종량 전환 결정, §10). 도메인 등 소액 고정비는 기존 사이트와 공유.

### 6-3. 인력
- **M0~M1** 개발 1(+기획/디자인 겸임) · **M2~M3** +디자인 1, 경험담 **수동 검수 오너 겸직** · **GA** 소규모 유지.

### 6-4. 향후 비용이 생길 수 있는 지점(사전 인지)
- 무료 티어 한도 초과(Firestore 읽기/쓰기·저장·Functions 호출) → Blaze 종량(소액부터).
- AI 심화를 **서버 AI로** 도입할 경우 AI 종량 발생 → 그래서 **BYOK(사용자 키)** 로만 확장(서비스 비용 0 유지).

## 7. 보안 · 프라이버시 태세 ★

Waymark은 사용자의 **가장 사적인 데이터**(결정·감정·대화)를 다루고 **외부 LLM에 맥락을 전송**한다 → 보안이 최대 리스크다. 전담 규범 [security_spec](security_spec.md)로 관리하며, 경영 관점 요지:

| 축 | 태세 |
| :--- | :--- |
| **기밀성** | 결정·대화는 본인 외 비공개(운영자도 접근 불가) — **Firestore Security Rules + App Check로 구조적 강제** |
| **AI 데이터 보호** | 체험 AI는 **학습 안 하는 무료 티어(Groq·ZDR)만**·최소 전송·인젝션 방어. **Gemini/Mistral/Cohere 무료 금지**(학습). BYOK는 키 티어에 프라이버시 의존 → 고지·OpenAI/Anthropic 권장 |
| **공개 통제** | 경험담만 외부 노출, **동의·익명화·사람 검수 3중 관문** |
| **컴플라이언스** | 개인정보보호법(PIPA) 1차 · 국외 시 GDPR · 삭제·내보내기 권리 · DPA(위탁) |
| **사고 대응** | 탐지→격리→규명→복구→**법적 통지**, 연 1회 훈련 |
| **출시 게이트** | M3 전 Firestore Rules+App Check·침투테스트(IDOR 0)·시크릿 0·동의/삭제 검증 필수 |

> 위협 모델·Firestore Rules·프라이버시/컴플라이언스·사고 대응·출시 보안 게이트 전문은 [security_spec](security_spec.md).

## 8. 성공 지표

- **North Star** — "곁에 있었다" 지표: 주당 결정 1건+ 기록 & 먼저찾아옴 1회+ 응답한 사용자 비율.
- **MVP/베타 KPI**: 4주 리텐션 ≥ 30% · 체크인 응답률 ≥ 40% · 회고자 경험담 기여율 ≥ 15% · 경험담 "도움됐어요" ≥ 50%.
