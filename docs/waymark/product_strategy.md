## 1. 한 줄 정의 · 문제 · 기회

> **Waymark은 "결정의 갈림길에서 먼저 다가와 곁을 지키는 AI 동반자"다.** 결정을 대신 내려주지 않는다 — 기록하고, 먼저 찾아오고, 같은 길을 지난 이의 이야기를 건네고, 다시 보게 한다.

| | 내용 |
| :--- | :--- |
| **문제** | 결정을 자주·많이 내리는 사람은 (1) 큰 결정의 **외로움·사후 불안**을 혼자 감당하고 (2) 지난 결정을 **되돌아볼 기록·계기가 없어** 같은 후회를 반복한다. 조언 콘텐츠는 넘치지만 "그 순간 곁에 있어 주는 것"은 없다. |
| **기회** | 조언(answer) 시장은 포화지만 **동반(company) + 회고 자산화**는 비어 있다. "먼저 찾아옴"은 기존 저널/노트 앱에 없는 신호다. |
| **왜 지금** | 결정 동반은 LLM 없이도 **규칙·템플릿 + 먼저 찾아오는 타이밍**으로 핵심을 만들 수 있고, 통합 PWA·**기존 Cloud Run·Firestore·Scheduler·이메일 엔진 재사용**으로 1인~소규모가 **운영비 ≈ 0원**으로 운영 제품을 낼 수 있다. |

## 2. 타깃 페르소나

### 2-1. Primary (MVP 최적화 대상)

**"결정 피로를 겪는 실무 리더" — 지우(가상), 34세, 8년차 PO**

| 항목 | 내용 |
| :--- | :--- |
| 상황 | 제품·팀·커리어 결정을 매주 여러 건. 큰 결정 뒤 밤에 반추, "이게 맞았나" 불안. |
| 목표 | 결정을 덜 외롭게 내리고, 나중에 "그때의 나"를 돌아보며 **패턴을 학습**하고 싶다. |
| 불편 | 회고 습관을 원하지만 혼자서는 안 된다. 조언은 많아도 **공감·동반**은 없다. |
| 맥락 | 모바일 중심, 짧은 틈새 시간. 알림에 민감(업무 중·야간 **조용시간** 필요). |
| 성공 경험 | "결정하고 2~3일 뒤 Waymark이 먼저 안부를 물어, 혼자가 아니라고 느꼈다." |

### 2-2. Secondary (확장)

인생의 큰 갈림길(이직·관계·큰 구매·진학)을 앞둔 **일반 사용자**. 소개 페이지의 "결정하는 누구나"와 연결된다. **MVP는 Primary에 최적화**하되, 카피·도메인 태그는 보편적으로 둬 Secondary도 수용한다.

> **설계 원칙**: 제품 UX는 Primary로 뾰족하게, 브랜드 카피는 보편적으로. (소개 페이지에서 대상 축소 표현을 뺀 것과 동일 선상)

## 3. 핵심 가치 · 포지셔닝

- **핵심 가치 3**: **먼저**(서비스가 찾아온다) · **내게 맞게**(내 결정·감정 맥락 기반) · **살아있게**(관계가 지속된다)
- **한 문장 경계 (vs ReLearn)**: *"ReLearn은 성장을 돕고, Waymark은 결정을 지킨다."*
- **드리프트 하드룰**(= 이 선을 넘으면 Waymark이 아니다):
  1. Waymark은 **일상 배움·콘텐츠 큐레이션을 하지 않는다**(ReLearn의 일).
  2. Waymark은 **결정을 대신 내리지 않는다** — 갈림길을 비추고 곁에 있을 뿐.
  3. AI 톤은 **정서 동반자** — ReLearn의 성장 코치 말투와 분리.
  4. 단위는 **개별 결정(사건)** — 하루·주 반복 리듬이 아니다.

## 4. 핵심 루프 (개요)

```
   ┌─────────────────────────────────────────────────────────┐
   │                                                         │
   ▼                                                         │
① 결정 기록 ──▶ ② 먼저 찾아옴 ──▶ ③ 경험담 ──▶ ④ 다시 보기 ──┘
 (사용자 입력)   (시간 규칙 알림)   (커뮤니티)   (회고·결과 기록)
                                                   │
                                                   └─▶ 익명화하여 ③ 경험담으로 기여(선순환)
```

1. **결정 기록** — 결정의 순간·맥락·감정을 빠르게 캡처
2. **먼저 찾아옴** — 시간 규칙(T+0/+2~3일/+2주/+1달)에 서비스가 먼저 체크인·회고 유도
3. **경험담** — 같은 도메인·감정의 "겪어 본 사람" 이야기를 그 순간 노출(커뮤니티 제출 기반)
4. **다시 보기** — 그때 vs 지금 비교·결과 기록·패턴 회고 → 회고 산물을 익명 경험담으로 기여

> 상세 동작·수용 기준은 [functional_spec §3](functional_spec.md).

## 5. MVP 범위 (In / Out) ★

오너 확정: **풀 루프(경험담 포함) · 경험담=사용자 커뮤니티 제출 · 먼저찾아옴=시간 규칙**.

### 5-1. In (MVP에 포함)

| # | 기능 | 비고 |
| :--- | :--- | :--- |
| 1 | 가입·온보딩 | 소셜 로그인, 조용시간·알림 동의 |
| 2 | 결정 기록(캡처) | 제목·맥락·선택지·결정·감정·도메인·중요도·되돌림 |
| 3 | 홈(결정 타임라인 + 다가온 알림) | 진행 중/회고 대기 결정 한눈에 |
| 4 | 먼저 찾아옴 (시간 규칙) | **이메일(기존 엔진) + 웹푸시 + 인앱** 이중 채널, 조용시간 준수 |
| 5 | 동반 메시지 (4톤) + AI 체험 | 규칙·템플릿 기본 + **체험 AI(Groq 무료·무학습·ZDR·캡·₩0)** + 템플릿 폴백, 지속은 **BYOK** |
| 6 | 경험담 매칭·노출 | 도메인·감정 태그 + 의미 유사도 |
| 7 | 경험담 작성·제출 | 익명 기본, 회고 산물에서 유도 |
| 8 | 경험담 검수(모더레이션) | AI 선필터 + 사람 승인 큐 |
| 9 | 다시 보기·결과 기록 | 그때/지금 비교, 패턴 태그 |
| 10 | 알림 센터·설정 | 조용시간, 주기, 푸시 on/off |

### 5-2. Out (v2 이후)

**서버 유료 AI·무제한 채팅** · 임베딩 매칭 · 감정·내용 기반 AI 트리거 · 협업필터형 추천 · 팀/공유 결정 · 분석 대시보드 · 결제/프로 티어 · 네이티브 앱 · ReLearn 연동(통합 아님). *이유: 정체성이 서기 전 연동·수익화는 "비슷한 둘"로 뭉개질 위험(드리프트 하드룰 5).*

## 6. 성공 지표

### 6-1. North Star
**"곁에 있었다" 지표 — 주간 동반 완결률**: 한 주에 결정 1건+ 기록하고 **먼저찾아옴에 1회+ 응답**한 사용자 비율. (제품의 본질 = 먼저 찾아와 응답을 끌어내는 관계)

### 6-2. MVP KPI

| 영역 | 지표 | 1차 목표(베타) |
| :--- | :--- | :--- |
| 획득·유지 | 4주 리텐션 | ≥ 30% |
| 핵심 행동 | 주당 결정 기록 수(활성자) | ≥ 2건 |
| 먼저찾아옴 | 체크인 알림 응답률 | ≥ 40% |
| 경험담 | 회고 완료자의 경험담 기여율 | ≥ 15% |
| 경험담 | "도움됐어요" 비율(노출 대비) | ≥ 50% |
| 정서 | 결정 상세의 "덜 외로웠다" 체크 | 정성 추적 |

## 7. 로드맵 · 마일스톤

| 단계 | 내용 | 산출물 | 시점(목표) |
| :--- | :--- | :--- | :--- |
| **M0 설계·셋업** | 문서 세트 확정, **Firebase(Firestore·Auth·Hosting) 셋업**, 디자인 토큰 이식 | 레포·스키마·CI | 2026-11 |
| **M1 핵심 루프 알파** | 기록·홈·시간규칙 먼저찾아옴·AI 1~2모드·다시보기 | 내부 dogfooding | 2026-12 |
| **M2 경험담 + 4모드** | 제출·검수·매칭·노출, AI 4모드 완성 | 기능 완성 | 2027-01 |
| **M3 비공개 베타** | 초대, 시드 경험담, 알림 안정화, KPI 계측 | 베타 빌드 | 2027-02 |
| **M4 공개 베타 → GA** | 온보딩 다듬기, 성능·안정성, 공개 | 정식 출시 | **2027-03** |

> 승격 게이트: 각 단계는 "직전 단계 KPI·안정성 충족" 시에만 다음으로. 특히 **M2→M3는 경험담 콜드스타트(시드 ≥ N건)·검수 파이프라인 가동**이 조건.

## 8. 리스크 · 가정

| 리스크 | 영향 | 완화 |
| :--- | :--- | :--- |
| **경험담 콜드스타트** | 초기 경험담 0 → 루프 ③ 공허 | 오너·얼리어답터 시드 + 회고→기여 선순환 + 시드 없을 땐 AI 모드로 대체 노출 |
| **알림 피로** | 먼저찾아옴이 스팸처럼 느껴짐 | 조용시간·주기 사용자 제어, 중요도별 차등, 응답 없으면 감쇠 |
| **원칙 위반(대신 결정)** | 브랜드 붕괴·신뢰 상실 | AI 시스템 프롬프트 하드룰 + 응답 가드레일 + QA 체크리스트 |
| **프라이버시** | 결정은 매우 사적 | 기본 비공개, 경험담은 명시 동의·익명화·검수 |
| **ReLearn 드리프트** | 정체성 흐려짐 | 하드룰 4종, MVP에서 ReLearn 연동 금지 |

### 가정
- 1인~소규모 팀이 운영 가능한 **운영비 ≈ 0원** 스택(기존 Firebase 재사용 · AI = **학습 안 하는 무료 티어 체험(Groq·ZDR) + BYOK**).
- Primary 사용자는 **모바일·PWA**로 충분(네이티브 앱 불필요, MVP).

## 9. 비즈니스 모델 (방향만)

MVP는 **무료**로 관계·리텐션 검증 — **운영비 ≈ 0원(서버 AI·유료 백엔드 없음)이라 무수익에도 지속 가능**. 이후 프로(심화 회고·BYOK AI 관리·경험담 프리미엄) 검토. *수익화는 Out(v2+). 정체성·리텐션이 먼저다.*
